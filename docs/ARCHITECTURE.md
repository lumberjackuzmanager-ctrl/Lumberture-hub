# Lumberture Hub — тузилиши

Flask + waitress, SQLite (data/rent.db). Сервер: кассир ПК, D:\LumbertureHub, http://192.168.1.101:8081.
Ишга тушириш: `start.bat` → `serve.py` (фон вазифалари, restart.flag, кечки бэкап, watchdog).

## Асосий оқимлар
- **1С → платформа:** `c1.py` (DBF ўқиш, фақат ўқийди), `erp.py` (кўзгу, накладной, приход, тўлов; рақамлар 1С билан битта кетма-кетликда, `fix_collisions`).
- **Цех боти:** `raspil_bot.py` (@lumberture_workshop_bot) + `raspil.py` (ишлар, KPI, накладнойсиз иш → `code_doc_sync` черновик), `pickup.py`, `logist.py`, `edgebot.py`, `owner.py`.
- **Мижозлар боти:** `online.py` (@Lumberture_bot, онлайн буюртма, сайтга кириш коди). Ижарага боғланмайди.
- **Бот тиллари:** `botlang.py` + `lang/bot.json` (uz кирилл/лотин, ru, en).
- **UI тиллари:** `i18n.py` + `lang/ui.json` (калит — русча матн).
- **Касса:** `kassa.py`. **Бэкап:** `backup.py` (data/backups, D:\LumbertureHub_backups, OneDrive).
- **Разовые ишлар:** data/patch_once.sql (SQL), data/fetch_once.json (файл юклаш) — `c1.apply_*_file`.
