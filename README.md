# Арендаторы + клиенты-должники (Flask + SQLite + waitress)

Учёт аренды (площадь × ставка за м² с историей, свет по счётчику, мусор, компрессор, произвольные виды сборов),
счета, оплаты, баланс (долг/переплата), отчёты и Excel, модуль «Клиенты-должники».
Мультивалютность: у вида сбора валюта USD/UZS (аренда и компрессор — $, свет и мусор — сумы), оплаты в $ или сумах, итоги — в $
по текущему курсу (бот @em_mat_info_bot → ЦБ → вручную; `rates.py`), подробно — README_WINDOWS.md, раздел 7.1.
Начальные (старые) долги арендаторов и клиентов — в карточке, таблицей «Начальные долги» или импортом из Excel (раздел 7.2);
при вводе сообщения не отправляются, в балансе и напоминаниях учитываются.
Тексты уведомлений (счёт, оплата, напоминание, баланс; Telegram и SMS) — короткие: приветствие + итог в $; язык — русский или
O'zbekcha (латиница) у каждого арендатора/клиента, общий по умолчанию в «Настройках», шаблоны по языкам (раздел 7.3).

Уведомления: **Telegram с отдельного пользовательского аккаунта по номеру телефона** (MTProto, Telethon:
contacts.importContacts → send_message), очередь в БД с паузой 20–60 сек., дневным лимитом, часами отправки, обработкой
FloodWait/PEER_FLOOD; резерв — SMS (Eskiz.uz / Play Mobile / тест-режим, по умолчанию выключен);
дополнительно — Telegram-бот (long polling, по умолчанию выключен).

- Запуск: Windows — `start.bat` (порт 8081), Linux — `./run.sh`. Установка и инструкции — **README_WINDOWS.md**.
- Вход по умолчанию: `admin` / `admin123` (смените сразу — пока пароль стандартный, вверху страниц предупреждение).
- Безопасность (`security.py`, страница «Безопасность»): блокировка подбора пароля, журнал входов, политика паролей, автовыход,
  CSRF, заголовки безопасности, доступ по IP (по умолчанию — только этот ПК); README_WINDOWS.md, раздел 13.
- Резервные копии: `backup.py` (30 копий + копия в облачную папку Google Диска / OneDrive, если есть).
- Данные: `data/rent.db`; сессия Telegram: `data/tg_user.session` (секрет, не входит в архив); журнал фоновых задач: `data/telegram.log`.
- Тесты: `python tests/test_app.py` и `python tests/test_security.py` (Telethon, Bot API и SMS заменены заглушками, сеть не используется).
- Скриншоты (Telegram имитируется, ничего не отправляется): `RENT_TG_SIMULATE=1 RENT_TG_FAST=1 python serve.py &` → `python tests/e2e_screens.py`.
  `RENT_TG_SIMULATE` и `RENT_TG_FAST` — только для демонстрации, в работе их не задавать.

Файлы: `app.py` (всё приложение), `rates.py` (разбор ответа бота о курсе, курс ЦБ), `tguser.py` (Telegram-аккаунт, Telethon), `tg.py` (Bot API), `sms.py` (SMS-провайдеры),
`demo.py` (демо-данные), `templates/`, `static/`, `serve.py` (waitress + фоновые потоки: очередь Telegram-аккаунта,
очередь SMS/бота, приём сообщений бота, планировщик).
