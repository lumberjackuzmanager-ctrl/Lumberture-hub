# Арендаторы — установка на Windows и работа

Программа для учёта арендаторов (мебельщики, маляры и др.): аренда за м², свет по счётчику, мусор, компрессор и любые
другие сборы, оплаты, долги/переплаты. Второй модуль — **клиенты-должники** (долги за услуги распила/кромки и за материалы).
**Уведомления** (счёт, «получена оплата, остаток долга», напоминания должникам Пн/Чт) приходят в Telegram **с отдельного
аккаунта фирмы прямо на номер телефона** — арендаторам и клиентам ничего не нужно подключать. Если у номера нет Telegram —
отметка «нет Telegram» и, когда будет подключён Eskiz.uz, SMS.

Работает на **одном компьютере** (компьютер CEO, рядом с программой зарплаты). Открывается в браузере с этого и других
компьютеров офиса по локальной сети. Порт **8081** (зарплата использует 8080 — они не мешают друг другу).

## 1. Python
Python уже установлен для программы зарплаты. Проверка: Win+R → `cmd` → `py --version` (должно быть Python 3.10 или новее).
Если нет — скачайте с https://www.python.org/downloads/windows/ и при установке отметьте **«Add python.exe to PATH»**.

## 2. Скопировать программу
Распакуйте `rent-platform.zip` в **`C:\LumbertureHub`** (путь без пробелов и русских букв, не на Рабочий стол).

## 3. Запустить
Дважды щёлкните **`start.bat`**. Первый запуск 1–2 минуты (создаётся `.venv`, скачиваются библиотеки — нужен интернет).
Откроется окно с адресами:
```
Na etom PK:      http://localhost:8081
V lokalnoy seti: http://192.168.1.22:8081
```
Не закрывайте окно — пока оно открыто, программа работает (для работы без окна — п. 5).

Откройте http://localhost:8081 → вход **`admin` / `admin123`** → сразу смените пароль: «Пользователи» → ✎ admin → «Новый пароль».
Для бухгалтера/кассира создайте отдельного пользователя с ролью «Кассир / бухгалтер» (оплаты, показания, счета, долги клиентов, отчёты;
без настроек и удаления записей).

## 4. Доступ с других компьютеров
**По умолчанию программа открывается только на этом ПК** (`http://localhost:8081`, ярлык «Аренда и должники» на рабочем столе).
Другие компьютеры не подключатся: сервер слушает только 127.0.0.1, правило брандмауэра «Rent 8081» выключено, и в программе разрешён только этот ПК
(«Безопасность» → «Доступ по IP»). Как открыть доступ другому компьютеру офиса — раздел 13.3.

## 5. Автозапуск
**Вариант А (просто):** Win+R → `shell:startup` → положите туда ярлык на `C:\LumbertureHub\start_hidden.vbs` (запуск без окна после входа в Windows).
**Вариант Б (при включении, даже без входа):**
```bat
schtasks /Create /TN "LumbertureHub" /TR "C:\LumbertureHub\start.bat" /SC ONSTART /RU SYSTEM /RL HIGHEST /F
```
Спящий режим должен быть выключен (уже сделано для программы зарплаты). Если ПК выключен в день выставления счетов
или напоминаний — программа сделает это сама при следующем включении.

## 6. Первые шаги (порядок настройки)
1. **«Виды сборов» → «Аренда»** — общая **ставка аренды за м²** и дата, с которой она действует. При повышении ставки добавьте новую строку
   с новой датой: старые счета не меняются, новые считаются по новой ставке.
2. **«Виды сборов» → «Свет»** — тариф за кВт·ч (тоже с историей).
3. **«Мусор»** — сумма в месяц по умолчанию (у каждого арендатора можно указать свою или отключить).
4. **«Компрессор»** — сумма в месяц; по умолчанию никому не начисляется — отметьте нужных арендаторов в таблице «Кому начислять»
   на странице вида сбора (или в карточке арендатора). Способ расчёта можно поменять (например, на «за м²»).
5. **Новые сборы** (вода, охрана, уборка, вывоз стружки…): «Виды сборов» → «+ Новый вид сбора» → название и способ расчёта:
   - *Фиксированная сумма в месяц* (своя у каждого или по умолчанию),
   - *За м² площади* (площадь × ставка),
   - *По счётчику* (показания × тариф с историей — появится отдельной вкладкой на странице «Показания»),
   - *Разовое* (вносится вручную в карточке арендатора).
   Ненужный вид можно отключить (снять «Активен»).
6. **«Настройки»** — название (подпись в сообщениях), контактный телефон, категории арендаторов (Мебельщик, Маляр, Другое — список редактируется).
7. **«Арендаторы» → «+ Добавить»** — название, помещение, **площадь**, телефон, категория, дата договора. Ставка аренды пустая = общая ставка;
   можно указать свою ставку за м² или фиксированную сумму аренды. Отметьте ежемесячные сборы и начальное показание счётчика.

## 7. Как считается
- **Аренда** = площадь × ставка за м² (действующая на 1-е число месяца), или фиксированная сумма из карточки.
- **Свет** = (текущее − предыдущее показание) × тариф (действующий на последний день месяца показаний). Предыдущее показание
  подставляется само (прошлый месяц или начальное из карточки). Исправили показание — следующий месяц пересчитается.
- **Счёт за месяц** формируется автоматически 1-го числа (настраивается) или кнопкой «Счета → Сформировать»: аренда + мусор +
  компрессор + прочие ежемесячные. Свет добавляется, когда внесены показания за этот месяц. Дублей не бывает.
- **Баланс** = все начисления − все оплаты. Положительный — долг, отрицательный — переплата (аванс), переносится на следующие месяцы.
  Итог показывается в **долларах** (см. 7.1).
- Карточка арендатора — полная история с нарастающим балансом; «Выписка» — за любой месяц/период (печать и Excel).
- «Отчёты» — сводка по всем арендаторам за месяц (сальдо на начало, начисления по видам, оплаты, сальдо на конец) + Excel
  (лист «Сводка» и выписка по каждому арендатору).

### 7.1. Доллары и сумы, курс
- У каждого вида сбора своя валюта («Виды сборов» → «Валюта»): **аренда ($ за м²) и компрессор — в долларах**, свет и мусор —
  в **сумах**; для нового вида валюту выбирает администратор. Оплату можно записать в $ или в сумах.
- Каждое начисление и оплата хранятся **в своей валюте** + курс на день операции (снимок). Ничего не пересчитывается задним числом.
- Долг ведётся двумя «кошельками»: в $ и в сумах. Оплата в сумах сначала гасит сумовый долг, остаток пересчитывается в $ по
  курсу **дня оплаты** и гасит долларовый (и наоборот для оплаты в $). Лишнее — аванс в валюте оплаты.
- **Итог / долг / баланс = долг в $ + долг в сумах ÷ текущий курс**, показывается так: «Итого: $X (≈ Y сум по курсу Z на дату)».
  Поэтому **долларовый итог немного «плавает» вместе с курсом — только за счёт сумовой части** (свет, мусор); долларовая часть не меняется.
- Счета и сообщения в Telegram: строки — в своей валюте, итог — в $ с курсом и датой.
- **Курс** берётся у Telegram-бота **@em_mat_info_bot** (команда `/rate_usd`, ответ вида `1$ = 11 840 UZS`) с аккаунта фирмы
  (тот же, что для уведомлений; боту только задаётся вопрос) — автоматически каждый день в **09:00** и кнопкой **«Обновить курс»**.
  Если аккаунт не подключён или бот не ответил — официальный курс ЦБ (cbu.uz); можно ввести курс вручную (страница «Курс $»,
  там же история курсов и настройки: бот, команда, час, покупка/продажа если бот начнёт давать оба курса).
  Источник и время курса видны на главной. Пока курс ни разу не загружен, используется условный 12 000 (с предупреждением).
- При обновлении со старой версии миграция автоматическая и ничего не удаляет: если по виду сбора уже есть начисления в сумах,
  его валюта не меняется (смените её в «Виды сборов» и задайте ставку в $ — новые начисления пойдут в долларах).

### 7.2. Начальные (старые) долги — перенос из прошлого учёта
- **Где вводить** (только администратор):
  - карточка арендатора → блок **«Начальный долг (перенос)»** (или форма «Изменить» / «Добавить арендатора»);
  - карточка клиента → **«Начальный (старый) долг»** (или форма клиента) — долг **без заказа**;
  - всё сразу: меню **«Начальные долги»** (или кнопка на страницах «Арендаторы» / «Клиенты-должники») — таблица всех арендаторов
    и клиентов: долг в $, долг в сумах, комментарий → **«Сохранить всё»**;
  - из Excel: там же **«Шаблон Excel»** (в нём уже есть все арендаторы и клиенты) → заполнить → **«Импорт из Excel»** →
    предпросмотр (что создастся/изменится, ошибки) → **«Записать»**. Можно сразу завести новых арендаторов (площадь, ставка $/м²,
    фикс. аренда, начало договора) и клиентов. Пустая ячейка — значение не меняется; 0 в долге — удалить начальный долг.
- Долг вводится **отдельно в $ и в сумах**; со знаком **минус — аванс** (переплата). Дата по умолчанию — день перед первым счётом
  (у клиента — перед первым заказом, если заказов нет — сегодня); комментарий — по желанию.
- Записывается одной строкой истории **«Долг на начало (перенос): комментарий»** в своей валюте (у клиента — с отметкой «Перенос»).
  Учитывается в балансе, итогах, отчётах и **плановых напоминаниях**; в счета за месяц не входит.
- При вводе **сообщения в Telegram не отправляются** (ни «оплата», ни «счёт»).
- Изменить — тем же блоком (или в таблице), удалить — кнопкой «Удалить» или ✕ в истории.
- Клиенты теперь тоже могут иметь долги и оплаты **в $**: итог по клиенту — в сумах (долг в $ × текущий курс).

Ежемесячный порядок работы: 1-го числа счета формируются сами → в первых числах внесите **показания** за прошлый месяц
(«Показания», таблица всех арендаторов) → по мере оплат нажимайте «+ Оплата».

### 7.3. Тексты уведомлений и язык (русский / O'zbekcha)
Все уведомления (счёт за месяц, оплата получена, напоминание о долге, баланс) — **короткие и только в долларах**:
приветствие + итоговый долг в $ (сумовая часть пересчитывается по текущему курсу; у клиентов-должников весь долг — тоже в $).
Без строк начислений, сумов и курса. Тот же текст уходит и в Telegram, и в SMS.

| Сообщение | Русский | O'zbekcha (латиница) |
|---|---|---|
| Счёт / напоминание / баланс | Здравствуйте, Расул! Ваша задолженность на 08.10.2026: $204.22. <фирма> | Assalomu alaykum, Rasul! 08.10.2026 holatiga qarzdorligingiz: $204.22. <фирма> |
| Оплата получена | Здравствуйте, Расул! Получена оплата: $100. Остаток задолженности: $104.22. <фирма> | Assalomu alaykum, Rasul! To'lov qabul qilindi: $100. Qolgan qarz: $104.22. <фирма> |
| Переплата | … Аванс: $30. | … Avans: $30. |
| Долга нет | … Задолженности нет. Спасибо! | … Qarzdorlik yo'q. Rahmat! |

Оплата в сумах показывается в $ по курсу дня оплаты.
- **Язык** — у каждого арендатора и клиента поле «Язык уведомлений» (карточка → «Изменить»): «По умолчанию», «Русский», «O'zbekcha».
  Общий язык по умолчанию — «Настройки → Общие → Язык уведомлений по умолчанию» (изначально русский).
- **Сразу нескольким:** в списках «Арендаторы» и «Клиенты-должники» отметьте галочки (верхняя — все) → внизу выберите язык → «Сменить язык».
- **Excel:** в шаблоне «Ввод начальных долгов → Скачать шаблон» есть колонка «Язык уведомлений» (Русский / O'zbekcha, можно ru / uz; пусто — не менять).
- **Тексты** редактируются в «Настройки → Шаблоны уведомлений» отдельно для каждого языка; «Вернуть все по умолчанию» — исходные тексты.

## 8. Уведомления в Telegram с аккаунта фирмы (по номеру телефона)
Программа отправляет сообщения от **обычного Telegram-аккаунта** (как будто бухгалтер пишет с телефона), но сама и автоматически.
Получатель видит обычное личное сообщение; ему не нужно ничего нажимать, искать бота или подписываться.
Белый IP и настройка роутера не нужны — нужен только интернет на ПК.

> ⚠ **Риск блокировки аккаунта.** Telegram следит за спамом. Аккаунт, который пишет многим людям, у которых его **нет в контактах**,
> может получить ограничение («может писать только взаимным контактам», PEER_FLOOD) или блокировку — особенно если получатели
> нажимают «Спам/Заблокировать». Поэтому:
> - заведите **отдельный номер** (новая SIM-карта) только для уведомлений — **не** личный номер и **не** основной номер фирмы;
> - перед началом рассылок попользуйтесь аккаунтом несколько дней как обычно: фото, имя «Бухгалтерия <фирма>», пара переписок;
> - не уменьшайте паузу (20–60 сек.) и дневной лимит (50 сообщений) — при большом числе должников рассылка просто растянется на 2 дня;
> - пишите только своим арендаторам и клиентам, вежливо, с названием фирмы и телефоном (шаблоны это уже делают);
> - попросите постоянных арендаторов **добавить номер в контакты** или написать ему «ок» — после этого риск для них почти нулевой.
> Если Telegram всё-таки вернёт ограничение, программа сама остановит отправку (FloodWait — на указанное время, PEER_FLOOD — на сутки),
> покажет предупреждение на «Главной» и продолжит позже. Проверить состояние аккаунта: напишите **@SpamBot** в Telegram с этого аккаунта.

### 8.1. Аккаунт и ключи api_id / api_hash (один раз, ~10 минут)
1. Вставьте новую SIM-карту в любой телефон, установите Telegram и зарегистрируйте аккаунт на этот номер.
   Имя: например «Бухгалтерия Lumberture», поставьте фото/логотип. Включите **двухэтапную проверку** (Настройки → Конфиденциальность →
   Облачный пароль) — запишите пароль.
2. На компьютере откройте **https://my.telegram.org** → введите этот номер в международном формате (`+998…`) → «Next».
3. Код придёт **в приложение Telegram** (сообщение от «Telegram»), не по SMS. Введите его на сайте.
4. Нажмите **«API development tools»**. Заполните форму: *App title* — `LumbertureHub`, *Short name* — `rentplatform` (5–32 латинских букв),
   *Platform* — `Desktop`, остальное можно не заполнять → «Create application».
   (Если сайт пишет «ERROR» — отключите VPN/блокировщик рекламы и попробуйте ещё раз через несколько минут.)
5. На странице появятся **App api_id** (число, например `1234567`) и **App api_hash** (32 символа). Это ключи доступа — никому их не пересылайте.

### 8.2. Вход в программе (один раз)
1. «Настройки» → **«Telegram-аккаунт для уведомлений»** → справа введите **api_id**, **api_hash** и **номер аккаунта-отправителя** → «Сохранить».
2. Нажмите **«1. Получить код»** — код придёт в Telegram этого аккаунта (на телефоне с SIM-картой).
3. Введите код → **«2. Войти»**. Если включена двухэтапная проверка — появится поле **облачного пароля** → «Войти».
4. Статус станет «Подключён: Бухгалтерия …». Внизу блока — «Проверка: сообщение на номер» — отправьте себе тестовое сообщение
   и посмотрите результат в **«Журнал»**.
Сессия сохраняется в файл `data\tg_user.session` — больше входить не нужно (даже после перезагрузки). На телефоне в Telegram →
Настройки → Устройства появится сеанс «LumbertureHub» — **не завершайте его** (иначе программа попросит войти заново и покажет это на «Главной»).
Файл сессии = доступ к аккаунту: не копируйте его на другие ПК и никому не отправляйте («Выйти из аккаунта» в программе удаляет его).

### 8.3. Как отправляется
- Номер получателя (из карточки) добавляется в контакты аккаунта-отправителя под именем арендатора/клиента, затем отправляется сообщение.
- Сообщения стоят в **очереди** и уходят **по одному** со случайной паузой **20–60 сек.**, не больше **50 в день**, только **с 8:00 до 21:00**
  (всё меняется в «Настройки → Ограничения»). Что не успело уйти — уходит позже, в том числе после перезапуска ПК.
  Сообщения, которые не удалось отправить за 3 дня, отменяются (статус «устарело»), чтобы не слать устаревшие суммы.
- **«нет Telegram»** — у номера нет Telegram или человек скрыл поиск по номеру. **«закрыто приватностью»** — человек принимает сообщения
  только от контактов. Такие отметки видны в списках, в карточках и в «Напоминания»; таким людям повторно не пишем (кнопка «проверить снова»
  в карточке сбрасывает отметку, например после смены номера). Если включён SMS-резерв (п. 10) — им уходит SMS.
- **«Журнал»** — все сообщения: канал (Telegram / SMS / бот), кому, телефон, текст, статус и причина ошибки. Кассир может смотреть журнал.

**Что приходит арендатору:** счёт за месяц с расшифровкой (при формировании счетов); «Получена оплата X сум. Остаток задолженности: Y сум»
(или «Переплата»); напоминание о долге **по понедельникам и четвергам в 10:00** (если долг не меньше порога; см. «Напоминания»).
Отдельное сообщение при вводе показаний счётчика по умолчанию выключено (меньше сообщений — меньше риск). Тексты меняются в «Настройки → Шаблоны».
Запись оплат и показаний никогда не ждёт Telegram: если нет интернета, сообщения просто подождут в очереди.

### 8.4. Дополнительно: Telegram-бот (необязательно, по умолчанию выключен)
Бот нужен только тем, кто сам захочет подключиться (ссылка /start или QR, кнопка «💰 Баланс»). Основная работа от бота не зависит.
Если бот включён и человек к нему подключился, сообщения ему идут через бота (без риска для аккаунта).
1. В Telegram: **@BotFather** → `/newbot` → имя (например `Аренда — Lumberture`) → username на `bot` (например `lumberture_arenda_bot`) → скопируйте **токен**.
2. «Настройки» → «Дополнительно: Telegram-бот» → вставьте токен → «Сохранить и проверить» → отметьте «Включить бота» → «Сохранить».
3. В карточках арендаторов/клиентов появится блок «Дополнительно: Telegram-бот» со ссылкой, QR-кодом и кнопкой «Копировать».
Используйте отдельного бота только для этой программы (иначе ошибка «бот уже используется»).

## 9. Клиенты-должники (услуги и материалы)
«Клиенты-должники» → «+ Добавить клиента» (имя, телефон, компания). В карточке клиента:
- **Долг по заказу** — № заказа, дата, описание, тип (услуги: распил, кромка… / материалы: ЛДСП, МДФ…), сумма, срок оплаты;
- **Оплата** — гасит долги по очереди, начиная со старых; **просрочка** = дней с срока самого старого непогашенного заказа;
- **Уведомления** — статус Telegram по номеру (Telegram ✓ / нет Telegram / не проверено) и канал, которым уйдёт сообщение;
- **Напомнить сейчас** (авто / только Telegram / только SMS), **пауза** напоминаний до даты или выключение для конкретного клиента.

**Автонапоминания:** «Напоминания» — по умолчанию **Пн и Чт в 10:00** (Ташкент) **арендаторам-должникам и клиентам-должникам**
с долгом от минимальной суммы (порог отдельно для арендаторов и для клиентов; каждую группу можно выключить). Сообщения уходят
с Telegram-аккаунта по номеру телефона (п. 8). В таблице «Следующий запуск» видно, кто получит напоминание и каким каналом,
а кто помечен **«нет Telegram»** — с ними свяжитесь иначе или включите SMS-резерв. Тексты — общие для арендаторов и клиентов
(п. 7.3, «Настройки → Шаблоны уведомлений»): долг клиента в сообщении — в $ по текущему курсу, на языке клиента.

## 10. SMS через Eskiz.uz (резерв, когда понадобится)
SMS — **резервный** канал: уходит тем, у кого нет Telegram (или закрыт приватностью), если включена галочка «SMS-резерв».
Сейчас он выключен, провайдер — «Тест — только журнал»: всё работает без аккаунта, SMS только записываются в журнал.
1. Зарегистрируйтесь на **https://my.eskiz.uz** (email + телефон), подтвердите почту.
2. Заключите договор (для ООО/ИП — по реквизитам, оформляется в кабинете) и пополните баланс.
3. **Шаблоны:** Eskiz отправляет только тексты, совпадающие с **одобренным шаблоном** (модерация обычно до 1 рабочего дня).
   В кабинете: раздел СМС → «Шаблоны» → добавьте текст напоминания и текст «получена оплата» в том виде, как они записаны в программе
   («Настройки → Шаблоны уведомлений», по одному на каждый язык), переменные части — по правилам Eskiz. Пока аккаунт в тестовом режиме, Eskiz пропускает только свой тестовый текст.
   Совет: латиница дешевле (160 символов в 1 SMS, кириллица — 70) — узбекские тексты (латиница) обычно умещаются в 1 SMS.
4. Отправитель: по умолчанию общий номер **4546**; своё имя отправителя (например, LUMBERTURE) регистрируется через Eskiz отдельно.
5. В программе: «Напоминания» → «SMS-провайдер» → **Eskiz.uz** → email и пароль кабинета (или секретный ключ API, если кабинет его выдаёт) →
   «Сохранить» → **«Проверить вход»** → внизу «Тестовое SMS на номер» на свой телефон.
6. Включите галочку **«SMS-резерв»** в блоке «Расписание». Тексты короткие (одна строка с итогом в $), русский — обычно 2 части SMS.
Ошибки видны в «Журнал SMS» (ответ провайдера). «Не прошёл модерацию / шаблон» — текст не совпадает с одобренным шаблоном.
**Play Mobile** — выберите «Play Mobile» и введите логин/пароль/originator из договора с Play Mobile.

## 11. Резервные копии
Все данные — в файле **`data\rent.db`**.
- `backup.bat` → копия в `data\backups\rent_ГГГГ-ММ-ДД_ЧЧММ.db` (можно при работающей программе; хранятся последние **30**);
  или «Пользователи» → «Скачать резервную копию».
- Каждый день автоматически (20:00): `schtasks /Create /TN "Rent backup" /TR "C:\LumbertureHub\backup.bat auto" /SC DAILY /ST 20:00 /F`
- **Копия вне ПК (облако):** если на ПК выполнен вход в **Google Drive для компьютера** (диск G: → «Мой диск») или в **OneDrive**,
  каждая копия дополнительно попадает в папку `LumbertureHub-backups` на этом диске (там тоже последние 30) и уходит в облако.
  Другую папку можно указать первой строкой в файле `data\offsite_dir.txt`. Состояние — «Безопасность» → «Резервные копии».
- В копии базы есть api_hash, токен бота и пароль SMS — храните копии как пароли (облако — только своё, с двухэтапной проверкой).
  Файл сессии Telegram (`data\tg_user.session`) и секретный ключ в копию не входят — после восстановления на другом ПК войдите заново (п. 8.2).
- Восстановление: остановите программу, замените `data\rent.db` копией, удалите `rent.db-wal`/`rent.db-shm`, запустите `start.bat`.

## 12. Демо-данные и обновление
В «Настройки» можно **создать демо-данные** (мебельщики, маляры, клиенты с пометкой «демо») и **удалить их одной кнопкой**.
Обновление: остановите программу, сделайте резервную копию, замените файлы программы (кроме папки `data`), запустите `start.bat` —
база обновится сама.

## 13. Безопасность
### 13.1. Что защищено в программе
- **Подбор пароля:** 5 неудачных попыток входа (логин + компьютер) → вход блокируется на 15 мин.; 20 неудач с одного адреса
  по любым логинам → блок адреса. Сообщение одинаковое для неверного логина и пароля. Разблокировать раньше — «Безопасность» → «Сейчас заблокированы».
- **Журнал входов** (90 дней): кто, когда, с какого адреса, успешно или нет — «Безопасность».
- **Пароли:** при смене — минимум 8 символов, буквы и цифры, не стандартный (admin123…), не содержит логин. Хранятся только как хэш
  (scrypt / pbkdf2); устаревший хэш обновляется при входе. Если у кого-то остался стандартный пароль — вверху каждой страницы предупреждение.
- **Автовыход:** администратор — через 30 мин. бездействия, кассир — через 8 ч.; сеанс не дольше 12 ч.
- **Cookie** HttpOnly + SameSite=Lax, защита всех форм от подделки (CSRF), заголовки X-Frame-Options DENY, CSP, nosniff, Referrer-Policy,
  страницы с данными не кэшируются браузером. Никакого режима отладки; при ошибке пользователь видит только код, подробности — в `data\errors.log`.
  Загрузка файлов — только .xlsx до 5 МБ.
- **Доступ по IP:** «Безопасность» → «Доступ по IP» — список компьютеров (IP или подсеть), с которых открывается программа, и отдельный
  (необязательный) список для администраторов. Этот ПК (127.0.0.1, ::1, его собственные адреса) разрешён всегда — закрыть доступ себе нельзя.
  С другого компьютера нельзя сохранить список, который отрежет его самого.

### 13.2. Сеть и брандмауэр Windows
- Программа слушает **только адрес 127.0.0.1** (строка `set HOST=127.0.0.1` в `start.bat`) — подключиться с другого компьютера
  невозможно в принципе, даже если брандмауэр выключен. Открывается на этом ПК по `http://localhost:8081`.
- Правила брандмауэра «Rent 8081» и «Payroll 8080» **выключены**. Зарплата (8080) тоже запускается только для этого ПК (`C:\PayrollPlatform\start.bat`).
- Внимание: на этом ПК брандмауэр Windows для **частной сети выключен**. Рекомендуется включить
  (командная строка от имени администратора: `netsh advfirewall set privateprofile state on`) — после этого проверьте, что общий принтер
  и папки по сети работают как раньше.
- Проброс портов на роутере **не нужен и не должен быть настроен** — программа не должна быть видна из интернета.

### 13.3. Как открыть доступ компьютеру в сети офиса (если понадобится)
1. В программе на этом ПК: «Безопасность» → «Доступ по IP» → добавьте адрес компьютера (например `192.168.1.30`)
   или всю сеть офиса `192.168.1.0/24` → «Сохранить».
2. В `C:\LumbertureHub\start.bat` замените `set HOST=127.0.0.1` на `set HOST=0.0.0.0` и перезапустите программу.
3. Командная строка **от имени администратора** — включить правило только для локальной сети:
```bat
netsh advfirewall firewall set rule name="Rent 8081" new enable=yes remoteip=localsubnet profile=private,domain
```
4. На том компьютере: `http://192.168.1.22:8081`. Закрыть снова — вернуть `127.0.0.1` в `start.bat` и
   `netsh advfirewall firewall set rule name="Rent 8081" new enable=no`.

### 13.4. Что сделать владельцу
- Пароль на вход в Windows этого ПК и блокировка экрана (Win+L) — программа открывается без пароля Windows любому, кто сядет за ПК, до автовыхода.
- Сменить стандартные пароли пользователей программы, если вверху страницы есть предупреждение.
- Telegram-аккаунт рассылки: включить **двухэтапную аутентификацию** (Настройки → Конфиденциальность → Облачный пароль).
- Роутер: сменить заводской пароль, **не настраивать проброс портов** (8080/8081), арендаторам — только **гостевой Wi-Fi** (отдельная сеть).
- Войти в Google Drive для компьютера или OneDrive — тогда копии базы будут уходить в облако автоматически.

## 14. Оформление
«Оформление» (меню администратора): тема — Светлая / Тёмная / Авто (как в Windows), цвет акцента (зелёный, синий, фиолетовый,
оранжевый, красный, графит или свой цвет), размер шрифта (Обычный / Крупный / Очень крупный), плотность (Обычно / Компактно),
название и логотип в шапке и на странице входа. Логотип — PNG или JPG до 1 МБ, хранится в `data\ui_logo.png|jpg`.
Изменения видны сразу (предпросмотр) и сохраняются для всех пользователей; «Сбросить по умолчанию» возвращает исходный вид.

## Частые проблемы
| Проблема | Решение |
|---|---|
| С других ПК не открывается | Окно `start.bat` открыто? Правило брандмауэра (п. 4)? Сеть «Частная»? Правильный IP? |
| Порт 8081 занят | `set RENT_PORT=8082 && start.bat`, откройте 8082 в брандмауэре |
| «Telegram-аккаунт не подключён» на Главной | Сеанс завершён на телефоне или файл сессии удалён — «Настройки» → «Получить код» → войти заново |
| «Неверные api_id / api_hash» | Скопируйте их ещё раз с my.telegram.org → API development tools (api_hash — 32 символа) |
| Код не приходит | Он приходит в приложение Telegram (чат «Telegram»), а не по SMS; нажмите «Получить код ещё раз» через минуту |
| «Пауза по требованию Telegram» / PEER_FLOOD | Telegram ограничил частоту или аккаунт. Ничего не делайте — программа продолжит сама. Проверьте @SpamBot; не снимайте паузу вручную |
| Сообщения «в очереди» и не уходят | Вне часов отправки (8–21), исчерпан дневной лимит или пауза — причина видна в «Журнал» и «Настройки» |
| У арендатора «нет Telegram», а он есть | Номер в карточке другой или скрыт поиск по номеру: исправьте номер / попросите добавить ваш номер в контакты → «проверить снова» |
| Telegram-бот: «Неверный токен» / «бот уже используется» | Скопируйте токен целиком; используйте отдельного бота только для этой программы |
| Свет не начисляется | Не задан тариф («Виды сборов» → «Свет») или текущее показание меньше предыдущего |
| Аренда 0 | Не задана общая ставка за м² или у арендатора площадь 0 |
